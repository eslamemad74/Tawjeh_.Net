# Employee Management System

A C# console application to manage employees, departments, onboarding processes, action history, and skills.

## How to Run the Project

### Prerequisites
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or higher installed.

### Steps to Run

1. Open a terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd "Employee Management System"
   ```
3. Run the application using the following command:
   ```bash
   dotnet run
   ```
4. Follow the on-screen menu options (1-11) to interact with the application.
